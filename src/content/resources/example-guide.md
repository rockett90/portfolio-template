This is an example guide. Delete this file and add your own to
`src/content/resources/`. It's written to show the article layout: a contents
rail on the left (it appears once a page has three or more `##` sections),
text at a readable width, and figures, tables, code and maths that run wider.

## Resources work three ways

Which one you get depends on the frontmatter:

- Add a **`file:`** field and the card shows a **Download** link. Put the file
  in `public/files/`. No page is created.
- Add a **`url:`** field and the card shows an **Open** link to something
  hosted elsewhere, such as a public repo, docs or a template. No page is created.
- Add **neither** (like this one) and a readable page is generated, with a
  **Read** link on the card.

## Figures and tables

An image on its own line, with alt text, becomes a captioned figure. The alt
text is the caption:

![The social preview card, generated by npm run images](/og.png)

Tables run wider than the text, so a parts list has room to breathe:

| Part | Value | Tolerance | Package | Notes |
|---|---|---|---|---|
| R1 | 10k | 1% | 0603 | Top of the feedback divider |
| C4 | 100n | 10% | 0402 | Decoupling, placed close to the pin |

### Smaller sections

`###` headings show indented in the contents rail. Lists, `inline code`,
**bold**, *italic* and [links](https://docs.astro.build) all work as you'd expect.

## Code and maths

Fenced code blocks are highlighted at build time, with light and dark themes:

```c
static void adc_isr(void) {
    uint16_t sample = ADC1->DR;     // read clears EOC
    ring_push(&adc_ring, sample);
}
```

Maths is written in LaTeX between dollar signs, inline like $f_c = \frac{1}{2\pi RC}$,
or as a block:

$$
V_{out} = V_{ref}\left(1 + \frac{R_1}{R_2}\right)
$$

> Block quotes render as a callout at the text width.

See `WRITING-CONTENT.md` in the repo for everything else.
